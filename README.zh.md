# Enhanced-index

直接在 Bilibili 和 YouTube 搜索页筛选视频。

[English](README.md) · **简体中文**

## 介绍

Enhanced-index 是一个适用于 Chrome / Edge 的浏览器扩展。它在搜索栏旁添加一个小按钮，点击后可以按时长、画质和播放量筛选视频。
使用前不需要构建项目、填写 API Key、安装 AI 模型，也不用提前设置。

## 快速开始

1. 下载本仓库的源代码 ZIP 并解压，或克隆仓库。
2. 在 Chrome 中打开 `chrome://extensions`；在 Edge 中打开 `edge://extensions`。
3. 开启**开发者模式**，点击**加载已解压的扩展**，选择包含 `manifest.json` 的目录。

首次安装时会打开欢迎页。

修改代码或下载新版本后，先在扩展管理页重新加载扩展，再刷新视频网站标签页。

时长可以直接输入 1 到 59 的整数。离开输入框或点击 `应用筛选` 后，扩展会将它补成分钟格式，不会在输入到一半时转换。全角数字 `１０` 也能识别。单独的 `0`、`60`、负数和小数不支持快捷补全，请使用 `00:00`、`60:00` 等完整格式。

### 提示

- 播放量按卡片显示的近似值比较，例如 `1.2万` 按 12000 计算。卡片没有显示的精确数字，扩展也无法还原。
- HD、SD 都选中表示不限画质，至少需要选中一项。
- YouTube 的 HD、4K、8K 等明确画质标识归为 HD，明确的 SD 标识归为 SD。仅凭标题中的 `4K` 无法判断画质。
- `保留筛选信息不全的视频` 默认开启。缺少筛选所需的信息时，扩展会保留卡片；如果已经读到的数据不符合范围，仍会隐藏该卡片。
- 点击 `恢复全部` 可清除所有条件并还原卡片。按 Esc 或点击面板外即可关闭面板。

## 已知限制

- 扩展只筛选当前已加载且能识别的搜索卡片，不会遍历整个平台、自动翻页或改变结果顺序。
- Shorts、播放列表、直播、非视频入口和无法识别的内容不在支持范围内，可能继续显示。
- YouTube 有时会稍后才加载卡片时长。扩展在读到时长前按未知处理，加载后再筛选。遇到无法识别的数字格式，也不会自行猜测数值。
- 目前，扩展无法从 B 站卡片中可靠地读出最高画质。如果只选 HD 或 SD，再关闭保留未知信息的选项，可能会隐藏全部已识别的 B 站视频。
- 要查询完整的画质信息，需要另外接入数据来源，并确认数据是否可靠。本版不调用视频或播放器接口。
- 网站改版可能导致扩展认不出卡片或搜索栏。反馈问题时，请附上能够复现问题的例子。

## 隐私与权限

扩展使用 `storage` 权限保存筛选条件，并在 `www.bilibili.com`、`search.bilibili.com`、`www.youtube.com` 运行内容脚本。

筛选条件只保存在浏览器本地的扩展存储中。扩展不读取 Cookie、不上传浏览历史、不收集使用统计，也不会将视频相关数据发送到服务器。筛选时，扩展只读取当前页面，控制卡片的显示和隐藏。欢迎页及其中的外部链接与筛选功能相互独立。
